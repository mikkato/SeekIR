## Живой захват на железе (8 с, `core/build/seekd --secs 8 --hotmap core/tests/hot.bin --dump …`)
```
0.2 к/с (img=1  ff=1 err=1 resync=13) span=15807.0..16059.0 Tцентр=10.8C
6.8 к/с (img=15 ff=2 err=1 resync=13) span=15787.0..16046.5 Tцентр=10.8C
[seekd] img=26 ff=2 errors=1 resync=13
```
- Инициализация+первый кадр ≈ 2–3 с; после стабилизации ≈ 6.8 img/с.
- err=1, resync=13 — ожидаемое поведение ресинка после предыдущей сессии (зафиксировано в skill).
- FF-кадры приходят автоматически (ff=2 за сессию) — ручная FFC не требуется.
- Температуры выдаются без пользовательской калибровки (дефолтный Планк, ±5 °C).
- Отключение (`skcap_close`) — чистое, без подвешивания.

## Численные ориентиры для regress
- span авто-режима на idle-сцене: 15240..16060 counts; T центра сцены 10.8 °C (стабилен между кадрами).
- После изменений P0 эти же команды на том же железе должны дать тот же порядок значений и 0 ошибок в устойчивом режиме (TEST-01 «после»).
