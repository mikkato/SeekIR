# ffmpeg — лицензия и соответствие

В этой папке лежит перераспространяемый бинарник `ffmpeg.exe`.

**Сборка:** gyan.dev "essentials" (https://www.gyan.dev/ffmpeg/builds/), ffmpeg 9.1,
собран с `--enable-gpl --enable-version3 --enable-libx264 --enable-libx265 --enable-libxvid --enable-libaom`.
Такой набор опций делает бинарник **GPLv3** (не LGPL).

**Соответствие GPLv3:**
- Полный текст лицензии: `LICENSE-GPLv3.txt` (рядом с этим файлом и рядом с `ffmpeg.exe` в дистрибутиве).
- Исходный код ffmpeg (немодифицированный upstream) — https://ffmpeg.org/download.html;
  параметры/скрипты сборки gyan.dev — https://github.com/GyanD/codexffmpeg.
  Письменный офер исходников предоставляется в течение 3 лет с момента передачи бинарника по запросу.

**Почему это не «заражает» остальное приложение:**
`ffmpeg.exe` — отдельный процесс, запускаемый через pipe (stdin/stdout), без линковки и без
встраивания кода. Обмен через конвейер — «mere aggregation» (простая агрегация) по толкованию FSF,
поэтому остальной код SeekIR остаётся под своей (проприетарной) лицензией; обязательства GPLv3
распространяются только на сам ffmpeg-бинарник.

Если потребуется исключить GPL-компоненты полностью — пересобрать ffmpeg без `--enable-gpl`
(напр. `--enable-libopenh264` для H.264); тогда можно вернуть пометку LGPL.
